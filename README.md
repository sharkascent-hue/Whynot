# WhyNot Bodrum

Designer clothes and shoes in Bodrum since 2014. Instagram: [@whynot.bodrum2](https://www.instagram.com/whynot.bodrum2)

A static site with no build step: open `index.html`, or deploy the folder to Vercel or GitHub Pages.

- **Pages:** `index`, `shop` (`?cat=` / `?brand=`), `product?id=N`, `brands`, `about`, `contact`
- **Store details** (WhatsApp, Telegram, address, hours, shipping text) are in `js/config.js`. Blank fields are hidden.
- **Products, brands, colours and sizes** are in `js/products.js`. Photos go in `images/products/`.
- **Videos:** `media/hero.*` is the man talking in the store (home hero). `media/store.*` is the product close-up video.
