# Best Store Marmaris

Designer down jackets, parkas and puffers for men, ladies and kids, sold from Marmaris, Türkiye, with worldwide delivery in 7–12 days.

It's a static site with no build step: open `index.html`, or deploy the folder on Vercel.

- **Pages:** `index`, `shop` (`?cat=` / `?brand=`), `product?id=N`, `brands`, `about`, `contact`
- **Store details** are in `js/config.js`: WhatsApp, phone, address, hours and Instagram. Blank fields are hidden.
- **Products, brands, colours and sizes** are in `js/products.js`. Photos go in `images/products/`.
- **Hero video:** `media/hero.*`
